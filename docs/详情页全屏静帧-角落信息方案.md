## 1. 全屏静帧（背景）

- 容器：`.detail-stage` 铺满视口（扣除或不扣顶栏均可，推荐 **含顶栏下整屏仍是 still**，顶栏半透明叠上）。
- 图片：`width/height:100%`；`object-fit: cover`；`object-position: center`（个别条目若人脸被裁，可数据侧加 `still_focus`，本阶段默认 center）。
- **禁止：** `object-fit: fill`、非等比 `scaleX/Y`、把 still 压进固定比例盒子导致拉伸。
- 全屏极轻暗角 / 胶片颗粒可保留；**不要**再铺整屏死黑导致仍像「半页纯色」。

## 2. 经典金句：位置与可读性遮罩

### 位置（1920 建议）

| 方案 | 位置 | 适用 | 推荐度 |
|------|------|------|--------|
| **C1 下三分之一偏左**（主推） | 金句块左缘约 8–10% 宽；底边约距视口底 18–22% | 多数横构图 still | ★★★ |
| C2 光学中心 | 垂直约 46%、水平居中略偏左 | 短句、画面中心干净时 | ★★ |
| C3 偏右下 | 避开左上角图标与顶栏 | 仍面主体在左时 | ★ |

**主推 C1：** 电影字幕习惯、少挡人脸（人脸多在中上）、与右上角信息图标分区清晰。

### 字号（可沿用前案，略收因全屏叠字）

| 元素 | 1920 建议 |
|------|-----------|
| 中文 `line` | **40–48px**（短句可 52；>22 字 36–40）Serif |
| 英文 `line_en` | **15–17px** italic muted；最多 3 行 + clamp |
| 金句块 max-width | **640–720px** |

### 可读性遮罩（必须有，且要「局部」）

目标：金句可读，仍能感到全屏画面。

**推荐：文字背后的羽化底板，而非整屏 gradient 糊死。**

1. **主：文字衬底**  
   - 金句块背后一层 `radial-gradient` 或圆角矩形  
   - 中心约 `rgba(10,10,12,0.72–0.82)`，向外 40–60px 羽化到透明  
   - 或：`backdrop-filter: blur(8–12px)` + 半透明深色（注意性能，可降级为纯色羽化）
2. **辅：底部轻渐变（可选）**  
   - 仅下 35% 高：`transparent → rgba(10,10,12,0.45)`，帮助偏下排版，勿盖住上半画面
3. **禁止：** 整屏 0.9+ 不透明黑罩；右侧再砌实心大面板（即旧右台）

引号：金色 accent「」或左侧 2px 金竖线即可。

## 3. 角落图标：位置建议

| 候选 | 坐标（距边缘） | 优劣 | 结论 |
|------|----------------|------|------|
| **右上**（主推） | `top: 72–88px`（避开 56px 顶栏）、`right: 28–36px` | 符合「信息 / 更多」习惯；不挡 C1 金句 | **采用** |
| 右下 | `bottom: 36px` / `right: 36px` | 易与底栏合规字打架 | 备选 |
| 左下 | 易与返回/金句抢区 | 不建议 | — |

### 图标形态

- 尺寸热区：**≥44×44px**（可视图形 20–24px）
- 样式：线框圆 + `i` / 或「影片信息」抽象图标（三条横线+星也可）；描边 `rgba(232,228,220,0.55)`，hover 金色 accent
- 半透明圆底：`rgba(10,10,12,0.35)` + 细边，避免在亮 still 上消失
- `aria-label="影片信息"`；展开时 `aria-expanded="true"`

**不要用 emoji 当图标**（与站点精致胶片风不一致）；用 SVG 或 CSS 几何。

## 4. 悬浮框：内容结构

触发后出现在图标**下方偏左**（右上锚点 → 框向左下展开），避免出视口。

### 尺寸与样式（1920）

- 宽：**320–380px**
- 最大高：约 **420px**（内容少则自适应；**内部也不出滚条**——M1 字段短，够用）
- 背景：`rgba(18,18,24,0.94)` + `backdrop-filter: blur(16px)`；边框 `var(--border)`；圆角 8–10px
- 阴影：`0 16px 48px rgba(0,0,0,0.55)`
- 与图标间距：8–12px；右缘与图标右缘对齐或略内收 4px

### 内容顺序（自上而下）

```
┌─ 悬浮框 ─────────────────────────┐
│ 片名（中）          年份          │  ← 18–20px / year muted
│ 片名（英）                        │  ← 13–14px muted，有则
│ 角色 · {character}                │  ← 有则一行
│ 导演 · {director}                 │  ← 有则一行
│ ──────────────────────────────── │
│ [tag] [tag] [tag]                 │  ← 最多 3；无则整行隐藏
│ ──────────────────────────────── │
│ [豆瓣] [IMDb] [RT] [MC]           │  ← 复用现有徽章；无则隐藏
│ 评分截至 {as_of} · 策展快照…      │  ← 0.7rem dim；可截短
└──────────────────────────────────┘
```

**不放：** curator_note、license_note、poster、剧情长简介、外链大按钮墙。

## 5. 触达：hover / click

| 输入 | 行为 |
|------|------|
| **桌面指针 hover 图标** | 显示悬浮框；移出图标+框的合成热区后延迟 **150–200ms** 关闭（避免缝隙闪烁） |
| **click / tap 图标** | **切换**展开（兼容无 hover 设备）；再次点击或点舞台空白关闭 |
| **Esc** | 关闭 |
| **进页** | 默认收起；不自动弹出 |

实现建议：

- 用 `details/summary` 或 button + `popover` / 绝对定位面板均可；保持无滚条门禁。
- 热区：图标与面板包在同一 `.detail-info-anchor` 内，减少移出误关。
- 不要用纯 CSS `:hover` 且面板与图标不相邻（易抖）；允许极轻 JS。

焦点：打开后面板可 Tab 到徽章链接（若徽章带 url）；关闭后焦点回图标。

## 做什么 / 不做什么

### 做

- 背景 still 全屏 `object-fit: cover`，自适应裁剪、不变形  
- 默认 **只** 展示经典金句（+ 可选英文）  
- 右上角图标 → 悬浮框承载片名 / 导演 / tags / 评分  
- 金句区局部羽化遮罩，保证可读  
- 维持 1920×1080 无滚条、无小海报、无札记/图像说明展示  

### 不做

- 不恢复左右固定分栏为默认观感  
- 不默认摊开元信息与评分  
- 不把悬浮框做成第二屏或全宽抽屉（本阶段用角落小面板）  
- 不代写本轮前端；改沙箱交开发（New Bot）  
- 不 git push

1. 十条详情在 1920×1080：**无纵向滚条**；still **无拉伸变形**（正方形/竖图仍 cover）。
