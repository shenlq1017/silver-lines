## 角落布局（与 ℹ 关系）——主推

现沙箱 `.detail-info-anchor` 为右上 `top:80px; right:32px`，信息钮下方展开面板。

### 主推：同一行，音量在 ℹ **左侧**（旁）

```
 top: 80px                         right: 32px
                    ┌────┐ 12px ┌────┐
                    │ ♪  │──────│ ℹ  │
                    └────┘      └────┘
                     音量         信息
                         │
                         ▼ 信息面板仍锚在 ℹ 下方（右对齐）
                    ┌──────────────────┐
                    │ 片名 / 评分…      │
                    └──────────────────┘
```

| 规则 | 值 |
|------|-----|
| 容器 | 将 anchor 改为横向工具簇：`flex-direction: row`；`align-items: center`；`gap: 12px`；`align-items: flex-end` 仅用于「钮与面板」纵向时，面板应对准 **ℹ 列** |
| 推荐 DOM | `.detail-corner-tools`（横排：音量钮 + 信息锚点列）；信息面板仍在信息列内部向下开 |
| 尺寸 | 音量钮与 ℹ 同规格 44×44 |
| 互不挡 | 面板从 ℹ 下展开时，**左侧音量钮不被遮挡**；音乐与信息状态互不联动 |
| z-index | 与现信息钮同级（约 50） |

### 备选：音量在 ℹ **上方**（竖排）

若横排与顶栏视觉过挤，可竖排：`♪` 在上、`ℹ` 在下，间距 10px。  
面板仍从 ℹ 下开 → **不会盖住上方音量**。

### 明确不采用

- 音量放在 ℹ **下方**：与信息面板同槽，必互挡  
- 音量塞进信息悬浮框内：默认态找不到，违背「角落开关」  
- 左下角 / 金句旁：抢主视觉

## 行为补丁（实现要点）

1. `<audio id="detail-bgm" src="…/assets/audio/ambient.mp3" loop preload="metadata">`（路径按 `data-base` 拼）。  
2. 进页：不调用 `play()`；按钮为静音态。若 `sessionStorage` 为 `on`，**仍须等一次用户点击**（或本页内任意已有手势后）再 `play()`——推荐：**仅点击音量钮才出声**，会话记忆只恢复「下次点击前的图标态暗示」或「用户曾开启则图标显示为可播偏好，但仍要点一次」（简单做法：记忆仅用于「本会话内从 A 详情切到 B 详情时，若曾开启则在点击后自动续」——**M1 最小：** 记忆开关偏好，每次进详情仍默认静音 UI，若偏好为 on 则首次点击立即按 on 逻辑；更简单则 **同页会话内** 切条目前暂停，回详情若 storage=on 需再点一次）。  
   **M1 推荐最简：**  
   - storage=`on` 时，进入详情后若浏览器允许（已有用户手势手势链）可尝试 play；否则静音 UI，点一次即播。  
   - 不要静默失败还显示「播放中」。  
3. 点击切换：`on` ↔ `off`，写 `sessionStorage`，`loop` 常开。  
4. 离开详情（去列表/首页）：`pause()`。  
5. 无文件 / 404：隐藏音量钮或 `disabled`，不报红打断金句。  
6. 一屏门禁不变：无歌词、无进度条大控件。
