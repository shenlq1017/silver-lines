## 0. 硬规则（全程）

| 项 | 要求 |
|----|------|
| 编码 | 只在沙箱本地；**禁止 Cursor 云端编码代理** |
| 推送 | **禁止擅自 `git push`**；上架包由 **小记·项目经理** 终验后推，或用户/PM 明示放行 |
| 密钥 | **真实 API Key 永不进仓库**（见 §2）；只提交变量名与申请说明 |
| 素材 | 一律 TMDB **`/t/p/original`**；禁止 `w500`；禁止外链热图；文件落本地 `assets/` |
| 海报 | JPEG；宽边（较长边）**≥780** |
| 静帧 | 宽边优先 **≥2560**；源站最大不足 → 入库最大档并标 `meets_2560:false` / `actual`；**<1920 不上架** |
| 金句 | **quotes-only**（自 C27）：仅可核对银幕对白；不可核证片名 **不摄入**；merge 前跑 `scripts/check-quotes-only.py` |
| 精选 | `featured` 维持约 5 条，除非产品明确要求改变 |
| orphan | 已下载但未入库的海报/静帧可复用；**不要删除** |

## 1. 总流程（一眼看懂）

```
候选片单
  → 去重（相对 Top250 / 已有 batch / quotes / slug）
  → 批次 seed（TMDB 解析 id + 下海报 + 可选 backdrop 预检）
  → 静帧 ingest（TMDB backdrop → assets/stills）
  → 金句核证（quotes-only）
  → draft（data/cN-draft-quotes.json）
  → check-quotes-only → merge → sync-quote-pages
  → 冒烟 → PM 终验 → push
```

**片库元数据 ≠ 已上架金句。** `batch-*.json` 与海报只是备料；只有并入 `data/quotes.json` 且 `status=published` 才算上架。

建议上架粒度：**+25 / 一批**（反对一次铺开数百条）。

## 2. 需要用到的 Key（名称与申请；不含真实值）

### 2.1 唯一必需：`TMDB_API_KEY`

搜集链路（搜片、取详情、下海报、下静帧/backdrop 预检）**只依赖这一个密钥**。

| 项 | 说明 |
|----|------|
| 变量名 | `TMDB_API_KEY` |
| 用途 | The Movie Database (TMDB) v3 API：`/search/movie`、`/movie/{id}`、`/movie/{id}/images`；以及 `image.tmdb.org/t/p/original{path}` 下载 |
| 申请 | 见下方「申请步骤」 |
| 费用 | 个人开发用途免费；请遵守 TMDB 使用条款与合理速率（脚本侧约 0.25–0.3s/请求） |

**申请步骤：**

1. 注册免费账号：https://www.themoviedb.org/
2. 打开 API 设置：https://www.themoviedb.org/settings/api
3. 申请 **API Key (v3 auth)**，再按下方「加载方式」注入环境变量（**不要**把真实值写进仓库）

**加载方式（按优先级，勿把真实值写进 git）：**

```bash
# 推荐：当前 shell 临时导出（不会落盘）
export TMDB_API_KEY=   # 在等号后粘贴密钥；勿把含真实值的命令写进仓库

# 或：本机私有 env 文件（必须被 .gitignore 忽略）
# 例如 /workspace/tmp/mat-*/.tmdb.env 仅本机使用
# set -a && source /path/to/.tmdb.env && set +a
```

历史沙箱脚本也可能从本机 `box-secrets` 读同名键；**那是机器私有配置，不是仓库文件。**

### 2.2 明确不需要入仓的 Key

| 服务 | 是否需要 | 说明 |
|------|----------|------|
| Douban API | 否 | Top250 为冻结名单；评分是策展快照，禁止爬虫实时抓 |
| OMDb / Fanart / 其它 Bearer | 否 | 现行链路未用 |
| GitHub Token | 否（搜集阶段） | 推送由 PM / 授权账号在本机完成，不写进文档或仓库 |

### 2.3 防泄漏清单（提交前必查）

**永远不要**把下列内容 `git add` / commit / push：

- 真实 `TMDB_API_KEY` 字符串
- `.env`、`.tmdb.env`、`*.pem`、含密钥的 `box-secrets.json`
- 任何「把 key 贴进 markdown / 报告 / log」的文件

仓库应保留：

- 本文档中的 **变量名** 与 **申请链接**
- 可选：`.env.example`（只有空占位，例如 `TMDB_API_KEY=`）
- `.gitignore` 已忽略 `.env` / `.tmdb.env` / `box-secrets.json` 等

自检：

```bash
cd /workspace/silver-lines
git status
# 确认没有 .env / .tmdb.env / secrets
git grep -nE 'TMDB_API_KEY=.+' -- ':!.env.example' ':!docs/影片搜集指南.md' || true
# 若打出含真实密钥的行 → 立刻从暂存区拿掉，并轮换密钥
```

## 4. 步骤详解

### 4.1 候选片单

人工策展一份候选列表（常见落在 `/workspace/tmp/mat-{name}/candidates.jsonl`），字段建议：

- `title_en` / `title_zh` / `year`
- 可选：`tmdb_id`（已知则优先）、地区、标签（如 `dialogue-classic`）

**策展偏好（实践）：**

- 偏「有可核对银幕名句」的片，而不是只有氛围/主题的片
- 地区可混搭（美/港/陆/欧亚等）；丁线曾以 dialogue-classic 为主
- 不可核证对白的片名最终会 **drop**，不要硬写策展句充数

### 4.2 去重

相对下列集合排除冲突（任一命中即 skip）：

- `data/top250.json`（及已发布 Top249 意图）
- 已有 `data/classics-ext/batch-*.json`（除正在写的本批）
- `data/quotes.json` 已出现的片名/年份
- 已占用 `slug`、以及 `tmdb_id` / `imdb_id` / `douban_id`

键：`tmdb_id` · `imdb_id` · `douban_id` · `slug` · `title_zh+year` · `title_en+year`

### 4.3 批次 seed（海报 + 元数据）

操作脚本目前在沙箱临时目录（**尚未**全部晋升到仓库 `scripts/`）：

| 批次 | 典型脚本 |
|------|----------|
| jia2 | `/workspace/tmp/mat-jia2/ingest.py` |
| yi2 | `/workspace/tmp/mat-yi2/ingest.py` |
| bing | `/workspace/tmp/mat-bing/ingest_bing.py` |
| ding | `/workspace/tmp/mat-ding/ingest.py` |

示例（丁线）：

```bash
export TMDB_API_KEY=   # 仅本机环境，勿写入文件后 commit
python3 /workspace/tmp/mat-ding/ingest.py
# 可选：--limit 20 试跑；按脚本说明可加 --target N
```

脚本会：

1. 用 TMDB 解析/校验影片  
2. 下载 **original** 海报 → `assets/posters/classics/{slug}.jpg`（宽边 ≥780）  
3. 写入 `data/classics-ext/batch-{name}.json`  
4. （丁线）对 backdrop 做 **宽边 ≥1920** 预检 → `/workspace/tmp/batch-ding/curatable-preflight.json`  
5. **不**改 `quotes.json`；**不** `git push`

产出报告示例：`/workspace/tmp/batch-ding/seed-report.md`

**可策展（curatable）粗定义：** 海报合规 ∧（有宽边 ≥1920 的 TMDB backdrop，或本地已有合规静帧）。

### 4.4 静帧 ingest

按上架波次在 `/workspace/tmp/stills-*/ingest.py` 执行：从 TMDB images 取最大合规 backdrop，写到 `assets/stills/classics/{slug}.jpg`，并更新碎片索引后由统筹合并进 `data/stills-index.json`。

| 宽边 | 处理 |
|------|------|
| ≥2560 | 合格（`meets_2560:true`） |
| 1920–2559 | 可入库，标 soft / `meets_2560:false` + note |
| &lt;1920 | **不上架**（该片本波跳过） |

### 4.5 金句核证（quotes-only）

每片 **1** 条可核对银幕对白：

- `line`：对白正文（通行译法可）  
- `character`：说话角色（禁止「主题/旁白概括」占位）  
- `curator_note`：写明核证依据（Wikiquote / IMDb Quotes / AFI / 字幕 / 剧本 / 通行影评引文等）  
- **禁止**「策展句」「非逐字」「主题性」「概括题旨」等表述充数  

不可核证 → **drop**（资产可留作 orphan，不删）。

政策全文：[`quotes-policy.md`](./quotes-policy.md)。

### 4.6 Draft

写出例如 `data/c30-draft-quotes.json`（`status=draft`），字段对齐 `quotes.json`。  
配套报告可放 `/workspace/tmp/cN-draft/`（remaining / dropped / preflight）。

此阶段 **禁止** 改 `quotes.json`。

### 4.7 门禁 → 并入 → 同步

```bash
cd /workspace/silver-lines

# 1) quotes-only 门禁（必须 PASS）
python3 scripts/check-quotes-only.py data/cN-draft-quotes.json

# 2) 一次性 merge（各批脚本在 /workspace/tmp/cN-merge/merge-cN.mjs）
#    写入 quotes.json；featured≈5；去重；素材存在性检查

# 3) 详情壳同步
node scripts/sync-quote-pages.mjs

# 4) 本地冒烟
python3 -m http.server 8080
# 首页 /quotes/ /quotes/{id}/ 文案边界（金句 N · Classics CN）
```

未过门禁 → **禁止 merge**。  
默认仍 **禁止 push**；交 **小记·项目经理** 终验。

上架数据路径说明：[`data-driven.md`](./data-driven.md)。

## 6. 常见故障

| 现象 | 处理 |
|------|------|
| `ERROR: TMDB_API_KEY required` | 在当前 shell `export TMDB_API_KEY=…`；确认未把空值写进脚本 |
| 海报过瘦 / &lt;780 | 换 TMDB 其它 poster，或该片 skip |
| backdrop 全 &lt;1920 | 该片不可策展；静帧不上 |
| TMDB 搜到错片 | 人工指定正确 `tmdb_id` 后重跑；必要时走 id-repair |
| 金句门禁 FAIL | 改成可核对对白或 drop；禁止用策展句糊弄 |
| 误把 key 提交进 git | **立刻**从历史清除并在 TMDB 后台轮换密钥；通知维护者 |

## 7. 提交 Git 时的最小清单（搜集相关）

允许提交：

- 更新后的 `batch-*.json`、合规海报/静帧、`stills-index`、draft/合并后的 `quotes.json`（按批次流程）
- 文档（本文、政策、交接）
- `.env.example`、`.gitignore`

禁止提交：

- 任何真实 Key / `.env` / `.tmdb.env` / secrets
- 与本批无关的 orphan 垃圾文件（除非明确要入库）
- 未过 quotes-only 的「假金句」

推送默认走 PM 终验；用户明示「提交 GitHub」时，仍须先确认 **暂存区无密钥文件**。
