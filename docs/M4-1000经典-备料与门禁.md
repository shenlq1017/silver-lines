# 银幕金句 · M4「1000 经典」备料与门禁

> 拍板日：2026-09-25 · 统筹：New Bot · 验收：小记·项目经理  
> 现况锚点：`published=25`（M3 / `816b1df`）**冻结不动**，直至用户明示下一批上架范围。

## 1. 目标

- 长期目标：**约 1000 部经典电影 + 语录**（片库与素材先行，上架分批）。
- 近端只做：**备料（元数据 / 海报 / 静帧）+ 详情页模板化**；**不上架**超出 Top25 的金句。

## 2. 硬约束（全阶段）

| 项 | 要求 |
|----|------|
| 编码 | 沙箱本地；**禁止 Cursor/云端编码代理** |
| 推送 | **禁止擅自 push**；素材包 / 架构改动过 PM 验收后由 PM 推，或 PM 明示放行 |
| 上架 | `quotes.json` published **保持 25**，直到用户点名下一批（如 Top50） |
| 素材 | TMDB **original**；禁 w500、禁外链热图；本地 `assets/` |
| 静帧 | 宽边优先 **≥2560**；源站最大不足 → 入库最大档并标 `meets_2560:false` + note |
| 海报 | 同既有 Top250 门禁（高清 JPEG，过瘦/异常单独标记） |
| M3 线上 | 首页/墙/详情既有 Top25 **行为与视觉不回退** |

## 3. 五路并行（只备料）

| 路 | 范围 | 交付物 | 验收点 |
|----|------|--------|--------|
| A | 静帧 101–150 | `assets/stills/…` + `stills-index` 合并 | 50/50 齐；软例外有 note |
| B | 静帧 151–200 | 同上 | 同上 |
| C | 静帧 201–250 | 同上 | 同上 |
| D | 片库 251–500 | 元数据清单 + 高清海报 | 条数/命名/尺寸门禁；**无 published** |
| E | 片库 501–750 | 同上 | 同上 |

后续 751–1000、静帧对齐片库、金句策展：**另开批次**，不与五路抢推。

路径约定：Top250 内继续 `assets/stills/top250/`、`assets/posters/top250/`；扩展片库用独立目录（如 `assets/posters/classic/` + `data/catalog-*.json`），**命名规则先写进 ingest 文档再批量拉**。

## 4. 架构前置（上架扩量前必做）

- **现状**：列表数据驱动；详情「每 id 一份同壳 HTML」。
- **必改**：模板 + 脚本同步生成/更新详情壳，后续只动 `quotes.json` 与素材。
- **门禁**：改完后对现有 25 条详情冒烟（路由/静帧/音乐/信息角标）与 M3 一致，再允许下一批 published 扩量。
- 本改动可与五路备料并行，但 **merge 前单独终验**。

## 5. 上架节奏（与备料解耦）

```
备料过验 →（可选）金句 draft 包 → PM 策展验 → 并入 published + 详情同步
         → 沙箱冒烟 → PM 终验 → 推 main
```

- 默认下一批上架粒度：**用户确认后的一批**（建议 +25 或 +50，反对一次铺开数百条）。
- 无句 / 无合规静帧 / 无本地海报 → **不上架**。

## 6. 风险

1. 五路并行易脏仓：每路独立目录/索引字段，避免互相覆盖 `stills-index`。
2. 1000 目标易范围膨胀：片库元数据 ≠ 上架金句；PM 只认「备料包」与「上架包」两套门禁。
3. 详情未模板化前禁止批量加 HTML 壳。
4. 版权/可标注：继续 TMDB 可标注宣传物料口径；禁未授权原声。

## 7. PM 回执口径

- 备料包：齐套 + 软例外清单 → **有条件通过 / 退回**；通过后由 PM 推或明示开发推。
- 模板改造：25 条回归通过 → 放行。
- 上架包：策展 + 素材 + 冒烟 → 终验通过后 **PM 推 main**。
