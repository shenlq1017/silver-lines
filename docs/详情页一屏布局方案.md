设计靶面：**1920×1080** · 暗色胶片感 · 主视觉仍为大静帧 `still`  
状态：方案稿（不代写前端）；开发按门禁改沙箱模板与 CSS。

| # | 门禁 | 落地要点 |

## 推荐信息架构（唯一舞台）

**方案名：左静帧 · 右金句台（推荐）**

```
1920 × 1080
┌──────────────────────────────────────────────────────────────┐
│ [顶栏 52–56px · 半透明叠在舞台上]  Logo │ ←返回 │ 导航        │
├────────────────────────┬─────────────────────────────────────┤
│                        │  右栏 · 金句台（宽约 42%）            │
│   左 · 静帧舞台         │  垂直居中偏上                        │
│   （约 58% 宽）         │                                     │
│   still object-fit:    │   「中文金句」                        │
│   cover + 轻暗角       │   English italic（有则）             │
│   无叠字、无小海报      │                                     │
│                        │  ── 底部分隔线 ──                    │
│                        │  片名 / 英译 · 年份 · 角色            │
│                        │  导演（一行）· tags（胶囊）           │
│                        │  [豆瓣][IMDb][RT][MC]  · as_of 淡字  │
└────────────────────────┴─────────────────────────────────────┘
│ 底栏 28–32px（可选）：示意非原片 · 并入舞台底，勿再挂独立大 footer │
```

### 区域划分

| 区域 | 内容 | 角色 |
|------|------|------|
| A 顶栏 | Logo、返回金句墙、站点导航 | 导航；高度压到 ≤56px；`position:absolute` 叠舞台 |
| B 静帧 | `still` 全高 cover | 主视觉；禁止再叠小海报 |
| C 金句台 | `line` + 可选 `line_en` | **本页视觉中心** |
| D 片名元信息 | `film_title` / en · `year` · `character` · `director` · `tags` | 辅信息，紧贴金句台下方 |
| E 评分 | 现有徽章（imdb 必显，其余有则显）+ `as_of` 一行 | 右下或 D 同行右侧 |
| F 合规一句 | 「示意非原片截帧」 | 底栏淡字；**不**用 license_note 长文 |

备用（若产品更要「沉浸全幅」）：**全幅静帧 + 下三分之一叠字**。长英文易顶破一屏，故作备选，M1 优先左静帧右台。

## 金句字号 / 位置建议（1920）

| 元素 | 建议 | 说明 |
|------|------|------|
| 中文 `line` | **42–52px**（短句可到 56；>22 字回落到 40–44） | Noto Serif SC / 500–600；行高 1.45–1.55；字距约 0.04em |
| 引号 | 金色 accent「」或独立装饰竖线 | 勿再依赖超大引号抢戏 |
| 英文 `line_en` | **16–18px** italic · muted | 中文下 12–16px 间距；最长约 95 字需允许 2–3 行 |
| 垂直位置 | 右栏 **垂直居中略上**（光学中心约 46% 高） | 避免贴顶栏；下方留给 D+E |
| 右栏内边距 | 左右 48–64px，上下 ≥48px | 金句区 max-width ≈ 520–560px |

短句样例（「不疯魔，不成活。」）可略放大；长句样例（肖申克 / 阿甘）以不换行或最多 2 行为宜。

## 评分与片名如何塞进一屏

**原则：取消「影片信息」独立 h2 + dl 块；元信息与金句同台。**

推荐排布（右栏底部，约 160–200px 高预算）：

1. **第一行（片名行）**  
   `film_title`（强调，约 18–20px） · `film_title_en`（muted 14px） · `year` · `character`（「角色 · xxx」）
2. **第二行（制作行）**  
   `导演 · {director}` · tags 胶囊（最多 3，超出省略）
3. **第三行（评分行）**  
   徽章横排（沿用现有 `.badge`） · 右侧或下一行 `评分截至 {as_of}` 0.7rem dim  
   `source_note` 可截成短尾巴或仅 as_of（避免长文破屏）

**垂直预算（1080）粗算：**

- 顶栏叠层：56  
- 右栏可用高 ≈ 1080 − 56 − 32(底) ≈ **992**  
- 金句区（含英文）：≤ 420  
- 分隔 + D+E：≤ 220  
- 余量给留白：≥ 350  

超长英文：限制 `line_en` 最多 3 行 + `line-clamp`（详情页禁止滚动，宁可截断英文也不出滚条）。

## 1920×1080 线框要点（开发检查清单）

1. 详情页专用 class（如 `body.page-detail`）：`height:100vh; overflow:hidden`。  
2. `#detail-root` / `.detail-stage`：`height: calc(100vh - 0)` 或含顶栏后 `100vh` 单层 grid：`58fr 42fr`。  
3. 删除：`.detail-body`、`.detail-poster`、`curator_note` / `license_note` 注入、原独立大 `.site-footer`（详情改 slim chrome）。  
4. `still`：左栏 `object-fit:cover; object-position:center`；右栏用深色半透明面板（`rgba(10,10,12,.88–.94)`）+ 左边 1px 金线可选。  
5. 顶栏：从 sticky 文档流改为 **absolute / fixed 叠舞台**，避免再占流高度导致底部裁切。  
6. 返回链：放顶栏左侧或 Logo 旁，勿再占金句台一行大块。  
7. 验收：十条详情在 1920×1080 下 **无纵向滚动条**；窗口再矮时可降字号，但仍 `overflow:hidden`（本阶段不以小屏滚动为解）。

## 做什么 / 不做什么

### 做

- 详情改成 **单舞台一屏**；金句字号与位置整段重做  
- 片名 / 年份 / 角色 / 导演 / tags / 评分 **全部进右台下部**  
- 保留暗色胶片、颗粒、金色 accent、大静帧  
- 列表页海报可继续用；详情只用 still  
- 数据字段可保留；**UI 不展示**札记与图像说明长文  

### 不做

- 不代写本轮前端（本文件仅为方案；改沙箱由开发执行）  
- 不在详情加小海报、第二屏、长 dl、策展札记、图像说明区  
- 不引入播放器 / 外链大图墙 / 评论区  
- 不以「缩小 still 塞更多字」牺牲主视觉  
- 不把首页 / 列表也强行改成 100vh（仅详情门禁）  
- 本阶段不 git push
