关于银幕金句

Silver Lines · 电影质感的银幕金句策展站。当前为 Phase M1：锁定豆瓣 Top250 意图截取下的 Top10，各 1 条主金句。

本站是什么

收集值得回看的电影金句：大静帧叠字、暗色胶片风、评分徽章可视化。不做片源、不做播放器、不盗链外站媒体。

M1 范围

  • 静态 HTML + 本地 JSON（data/quotes.json）
  • 恰好 10 条 status=published，片名锁定 Top10
  • 海报 / 静帧为本地氛围示意 PNG（非原片截帧；待合规剧照替换）
  • 评分字段为策展快照（含 as_of），非实时抓取；详见 data/source.json

本地预览

在站点根目录执行：

cd /workspace/silver-lines && python3 -m http.server 8080

浏览器打开 http://127.0.0.1:8080/。勿直接用 file:// 打开（fetch 会失败）。

版权与素材声明

  • 金句文案：引用自公映电影对白，仅用于策展展示与评论，非商业片源分发。
  • 海报 / 静帧：自绘氛围 PNG 示意，非正式片宣物料、非原片截帧；正式上线前须替换为已授权或自有素材。
  • 评分徽章：展示策展写入的快照数值；不代表与豆瓣 / IMDb / RT / Metacritic 有任何官方合作。
